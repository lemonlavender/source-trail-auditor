# Report format

Use the sections below. Omit empty optional rows, but do not omit a section that contains a material gap.

## 1. Scope and as-of time

- Decision or question:
- Material reviewed:
- As-of time:
- Access limits:

## 2. Verdict

Choose `ready`, `ready-with-rechecks`, or `not-ready`. Explain the decision in two or three sentences.

## 3. Claim-source matrix

| Claim ID | Atomic claim | Source and exact location | State | Reason |
|---|---|---|---|---|

## 4. Source ledger

| Source | Publisher / type | Date | Access | Role |
|---|---|---|---|---|

## 5. Official task links

| Intended action | Best verified link | Why it is the action page | Gap |
|---|---|---|---|

## 6. Freshness queue

| Claim ID | Volatile field | Last supported date | Recheck target |
|---|---|---|---|

## 7. Source diversity and independence

Identify repeated claims that trace to the same origin and any decision-critical claim supported only by commentary.

## 8. Verification route

List unresolved items as `P0`, `P1`, then `P2`. Each item must name the claim, the exact page or page type to inspect, and the observation that would resolve it.

## 9. Rewrite guidance

Provide corrected wording only for claims whose support state is known. Preserve qualifications, dates, rollout scope, and uncertainty.

## 10. Coverage boundary

State which URLs were opened, which were excerpt-only or unavailable, and which conclusions remain provisional.
